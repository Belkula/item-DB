# Каталог игровых предметов

Небольшой прототип для добавления предметов в SQLite базу данных через терминал.

## Функции на данный момент

- Добавление предметов с названием, описанием и редкостью
- Проверка редкости предмета (от 1 до 6)
- Сохранение предметов в локальной ДБ

## Требования

- Python 3

## Как использовать

Открыть терминал в папке проекта и написать:
py main.py
